ただし対処はするな。理由:
ill-posed が C で1トークンとして出現するなら、俺が論文を読むときも
「ill-posed」という塊で出会う。単独の "ill" を予習する必要がない。

代わりに確認しろ: ハイフン語(ill-posed, sim-to-real, closed-form,
model-free, end-to-end 等)がそのまま L3/L2 候補として抽出されているか。

1トークン方針を維持したまま、ハイフン語自体が候補に上がるかを報告しろ。
